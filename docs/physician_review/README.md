# Physician review materials

The participant-facing instructions and blank worksheets accompany the physician audits in Appendix E.

- `00_医生审核说明.md`: review instructions and scoring rubric.
- `空白模板_80份输出评分.xlsx`: the 80 model outputs assessed by both physicians, with blank score cells.
- `空白模板_50例病例转换审核.xlsx`: the 50 source/conversion pairs, with blank score cells.

Completed individual ratings are confidential. Published aggregates are provided in `../../results/inputs/physician_review_summary.json` and `../../results/inputs/transformation_audit_summary.json`.

Automatic scores are not embedded in either worksheet. Output scoring and conversion fidelity are separate tasks. Each physician received CNY 2,000 for the review tasks.
