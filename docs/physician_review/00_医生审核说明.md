# 材料独立审核说明

您好！非常荣幸邀请您参加此次评审！请使用本目录中名称以 `空白模板_` 开头的两份 Excel 表。表中提供参考诊断和评分要点，但不提供系统自动评分。请只依据病例材料、临床判断和表内评分要点作答。

每行是一例。前面的病例与输出列是只读材料；仅填写右侧黄色评分列。保留 `audit_id`、`case_id` 或 `episode_id`，不要排序后删除行或改写病例内容。无法判断某项时留空，并在备注中简述原因；不要用最低分代替“无法判断”。完成后保留原文件名，交回本人的两份表格。

## 一、50 例病例转换审核

文件：`空白模板_50例病例转换审核.xlsx`。每行左侧 `BEFORE_*` 是原始 OSCE 病例的任务目标、患者信息、查体、检查结果和正确诊断；`AFTER_*` 是转换后交互式病例中的患者可见信息、可选检查类别及结果、参考诊断、证据与管理要点。逐行比较同一病例在转换前后的医学事实与信息分配。

表中的 `fid-` 与 `fid2-` 都是审核编号；按表格现有顺序逐行审核即可。

| 黄色列 | 填写规则 |
|---|---|
| `fid_diagnosis_preserved_YN` | 参考诊断的临床含义保持一致填 `Y`；疾病或关键亚型被改变填 `N`。可接受同义名称。 |
| `fid_history_exam_split_faithful_YN` | 病史、查体及检查信息的拆分与原题相符，且没有把需检查才得知的事实提前作为病史透露，填 `Y`；存在影响病例理解或诊断的信息错置、遗漏或改变，填 `N`。 |
| `fid_test_catalog_plausible_YN` | 可选检查类别及所呈现结果符合该病例的临床检查路径与原题事实，填 `Y`；关键检查不合理、结果矛盾或目录明显不适用，填 `N`。 |
| `fid_no_fabricated_critical_info_YN` | **未**新增会改变诊断、危险分层或处置的关键事实，填 `Y`；发现这类编造，填 `N`。一般措辞变化不算关键事实编造。 |
| `fid_overall_faithfulness_1to5` | `5`：关键事实、诊断和信息分配完整可信；`4`：仅轻微表述或非关键遗漏；`3`：有局部偏差，但病例核心仍可辨认；`2`：重要事实或信息分配有误，明显影响判断；`1`：诊断或关键事实失真，无法视为同一病例。 |
| `fid_notes` | 记录 `N` 或低分涉及的具体事实、字段及原因；也可记录无法判断的原因。 |

## 二、80 份输出评分

文件：`空白模板_80份输出评分.xlsx`。每行包含患者呈现信息、参考诊断及可接受名称、待评输出的最终诊断、证据、计划、随访，以及证据和管理评分要点。请按病例已给出的信息与合理临床做法评价该份输出；参考要点用于核对关键内容，不要求逐字一致。

同一 `episode_id` 可能对应不同的待评输出；每个 `audit_id` 都是一份独立评分，不要合并或删除。

| 黄色列 | 填写规则 |
|---|---|
| `phys_diag_grade` | 从下拉选项中选一个：`1.0 - exact`（诊断准确或等价同义）；`0.75 - mostly_correct`（主要方向正确，层级/亚型有轻微偏差）；`0.5 - partially_correct`（部分识别正确，但关键诊断不完整）；`0.25 - wrong_low_risk`（诊断错误，按该回答行动的额外临床风险较低）；`0.0 - dangerous`（诊断错误且可能造成有临床意义的伤害或延误）。 |
| `phys_evidence_score` | 选 `0 / 0.25 / 0.5 / 0.75 / 1`：分别表示未给出相关支持、少量相关、约半数关键要点、覆盖大部分关键要点、关键证据充分且与病例一致。对与病例矛盾的证据不能因文字较多给高分。 |
| `phys_plan_score` | 同一五档：分别表示缺失或明显不当、仅少量恰当措施、覆盖部分核心处置、覆盖大部分核心处置、处置及必要随访完整且临床适当。危险建议应在备注中标明，并据整体临床适当性降分。 |
| `phys_notes` | 可记录诊断分档的关键理由、遗漏或错误的证据/处置、危险建议，或无法判断的原因。 |

评分时逐项独立判断；诊断分数不自动决定证据或计划分数。若需查阅常规临床资料，可以查阅，并在备注中写明影响判断的依据。

## 提交前检查

确认 50 行转换审核与 80 行输出评分均逐行查看；每项可判断的评分都已填，无法判断的项保持空白且有备注；未修改非黄色材料列。两份表分别保存并交回。
